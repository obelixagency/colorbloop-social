# Visual Schedule Cards for Kids ($2.99, Etsy)
- `Visual_Schedule_Cards_US_Letter.pdf` + `_A4.pdf`: 13 pages (start page, My Morning / My Day / My Bedtime boards, First/Then board, 72 picture cards on 6 sheets, 12 blank cards, thank-you + credits).
- `vs_1..5.jpg`: listing images 1500x1875.
- Pictures: Noto Emoji (Apache 2.0) from npm @svgmoji/noto sprite, rendered with products/tools/emoji_png.py. Fonts: Fredoka (OFL, npm @fontsource/fredoka woff -> ttf).
- Rebuild: emoji_png.py SPRITE PNGDIR 600 code=code ... (codes in build/cards.py); make_pdf.py FONTDIR PNGDIR out.pdf; make_mockups.py FONTDIR OUTDIR letter.pdf -
